# Student Attendance Tracker

A simple responsive web application for recording student attendance by date.

## Features
- Add and remove student names.
- Choose an attendance date.
- Mark each student Present or Absent for the selected date.
- Switch dates to view and update that day's attendance independently.
- View total, present, absent, and attendance percentage.
- Stores data in the browser with localStorage.

## Run the project
Open `index.html` in a modern browser. No server or installation is required.

## Technologies
- HTML for structure
- CSS for layout and responsive styling
- JavaScript for attendance logic and date-wise records
- localStorage for saving data in the same browser/device

## Limitation
This is a front-end demonstration. Data is stored locally in the current browser and is not synchronized between devices or connected to a college database.
